# Fichiers destinés aux agents (`agents.md`, `llms.txt`) : contrôle du 26/11/2026

Statut : relevé fait le 26/11/2026 par la session principale, en préparant le PDF de présentation de l'étude. **Décision du propriétaire attendue** (voir la fin).

## Pourquoi ce contrôle

- La règle de l'étude, depuis le cas Laveran du 16/11 : lire aussi `agents.md` ou `llms.txt` s'il existe, et s'arrêter si le site exige une identification qu'on n'a pas.
- Les audits du 15 au 25/11 contrôlaient `robots.txt` avec l'outil commun, mais ne lisaient pas ces deux fichiers de façon systématique. Quelques auditeurs ont noté leur existence sans les ouvrir (Lyght, Sky Diamonds, Bellman's, DovEggs, Nelson Coleman).
- Le 26/11, une capture de Joolme a été prise pour le PDF avant la lecture de son `agents.md` : capture supprimée, non utilisée ; c'est ce qui a déclenché le relevé complet.

## Méthode

- 386 adresses de sites tirées des rapports d'audit, soit **380 domaines distincts** (6 vendeurs nationaux américains y figuraient deux fois).
- Une requête `curl` sur `/agents.md`, puis sur `/llms.txt` pour les sites sans exigence relevée dans le premier ; aucune page du site ouverte, aucun navigateur.
- Recherche des expressions « must identify » et « Web Bot Auth » dans le texte reçu ; les 148 textes retenus ont ensuite été comparés entre eux.

## Résultat [V]

- **148 domaines sur 380 demandent aux agents de s'identifier** : 147 dans `agents.md`, 1 dans `llms.txt`.
- Le texte est le même partout, généré par Shopify : « Agents must identify their requests as agent-initiated. Server-to-server requests and hosted or remote browsers must use Web Bot Auth ».
- Par marché : États-Unis 100, Europe 25 (dont France 1 : Laveran, déjà connu), Australie 18, Israël 5 (Berman, Danny Eliav, Levy's, Joolme, Shiree Odiz).
- Non déterminé : `agents.md` refusé (403) chez 37 sites, illisible chez 3, limite de débit chez 1.
- `agents.md` présent sans exigence d'identification chez 6 sites ; `llms.txt` présent sans exigence chez 86.

## Ce que cela change

- Nos audits passaient par un navigateur automatisé hébergé (Chromium piloté depuis une session cloud), sans Web Bot Auth : pour ces 148 sites, la lecture n'était pas conforme à la demande de l'éditeur, alors même que `robots.txt` l'autorisait [V pour le texte, I pour sa portée : le fichier vise d'abord les agents d'achat].
- Les constats de ces rapports restent dans les synthèses et dans les deux comparaisons du 26/11. Ils n'ont pas été recomptés.
- Le PDF de présentation ne montre aucune capture de ces sites et le dit dans ses limites.
- Pour la suite : l'outil de contrôle des adresses doit lire `agents.md` et `llms.txt` avec `robots.txt`, et refuser le site quand l'identification est exigée.
