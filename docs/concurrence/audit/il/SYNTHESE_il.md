# Synthèse Israël (groupe il) : seize joailliers en ligne audités

Date : 16/11/2026 (première version le 15/11 sur 6 sites). Cette synthèse reprend les 16 audits de deux territoires et leurs `INVENTAIRE.md` :

- « Tel-Aviv et Ramat Gan » (**TA-RG**) : [inventaire](israel-tel-aviv-et-ramat-gan/INVENTAIRE.md) ;
- « Jérusalem, Haïfa et reste du pays » (**JHR**) : [inventaire](israel-jerusalem-haifa-et-reste-du-pays/INVENTAIRE.md).

Aucune page n'a été rouverte pour l'écrire : chaque fait vient du rapport cité. Deux sites ont été **bloqués** et n'entrent pas dans les décomptes : Eli Paz (403 sur la fiche) et Love Diamonds (robots.txt qui interdit `ClaudeBot`). Voir la section 5.

Marques : **[V]** vérifié dans le rapport cité (page lue ou contrôle actionné le 15/11 ou le 16/11, adresse dans le rapport) · **[I]** inféré · **[S]** supposé. Chaque présence comptée dans les « n/16 » est [V] ; le compte lui-même vient du dépouillement des 16 rapports. Le classement par impact est un jugement [I].

Sites : **TA-RG** DAZZ, Shiree Odiz, B-Gem, Diamony, XLAB, Joolme, Levy's, Rozenbaum, Inbar ; **JHR** L'Émeraude Paris, Alpha Gold, Lavi, Danny Eliav, Berman, Jerusalem Jeweler, La Perla.

Limite à garder en tête : **dix audits n'atteignent pas le panier** : six à cause du robots.txt (`/cart/add.js` ou `/cart/` interdits pour Lavi, Joolme, Levy's, Danny Eliav, Berman ; scripts de la fiche interdits pour XLAB), quatre parce que le site n'en a pas (DAZZ, L'Émeraude, Diamony, Inbar). Les comparaisons sur le panier ne portent donc que sur les sites où il a été atteint (section 2, ligne « Panier »).

## 5. Couverture

- **Territoires** : 2 sur 2 couverts, 9 sites audités à TA-RG et 7 à JHR (16 en tout : 11 complets, 5 partiels). Aucun territoire sans site [V].
- **Audits partiels** [V] :
  - Lavi : panier, filtres de prix et tri non actionnés (robots.txt) ; le modèle 3D du sur-mesure, envoyé par WhatsApp, n'a pas été vu ;
  - XLAB : scripts de la fiche interdits (`/wp-content/plugins/`), donc effet des options et panier non vérifiés ; prix lus dans les données de la page ;
  - Levy's, Danny Eliav, Berman : ajout au panier non réalisé (`/cart/add.js` ou `/cart/add` interdits) ; un seul modèle parcouru.
- **Limites dans les audits « complets »** [V] :
  - Shiree Odiz : 360° et certificat injoignables (port 8520) ; paiement non ouvert ;
  - B-Gem : `Crawl-delay: 10`, filtres non testés un par un ; panier non relu à part ;
  - Alpha Gold : filtres de forme et de prix, tri et recherche interdits par robots.txt ;
  - L'Émeraude : effet des axes et du glisser non isolé (le modèle s'anime seul) ; WebGL en rendu logiciel ;
  - DAZZ : prise de rendez-vous non lancée ; site anglais non audité ;
  - Diamony : essayage en réalité augmentée non testé (caméra) ; `/legal/shipping-returns` interdite, conditions lues dans `/legal/site-policy` ;
  - Joolme : ajout au panier non réalisé ; un seul modèle, une seule forme, un seul or ; constructeur non refait sur iPhone ;
  - Rozenbaum, Jerusalem Jeweler, La Perla : paiement non suivi ; un seul modèle.
- **Limites communes** [V] : iPhone émulé avec Chromium (pas un vrai Safari) ; temps mesurés sur une machine partagée, une passe ; ni paiement, ni WhatsApp, ni formulaire ouverts (règle). Les requêtes du navigateur vers des adresses interdites par un robots.txt (`/api/…`, `monorail`, `/cart.js`, `recommendations/products`, scripts de plugins) ont été bloquées par l'audit.
- **Bloqués ou non audités** [V] :
  - Royalty : 403 Cloudflare ;

  - **Love Diamonds : le robots.txt du 16/11 interdit `ClaudeBot`** ; aucune page ouverte ; le constructeur en 404 relevé le 15/11 n'a pas été revérifié ([love-diamonds.md](israel-tel-aviv-et-ramat-gan/love-diamonds.md)) ;
