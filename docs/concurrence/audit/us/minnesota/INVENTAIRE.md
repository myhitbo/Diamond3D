# Inventaire des joailliers : Minnesota

Recensement du 24 novembre 2026, dans le cadre de l'étude de concurrence aux États-Unis. Lecture seule, comme un visiteur ordinaire : robots.txt de chaque site lu avant toute page (outil de contrôle `robots.cjs`, puis lecture du fichier entier pour les groupes visant les agents d'IA), aucun formulaire rempli ni envoyé, aucun compte créé, aucun bouton « Add to cart » actionné, aucun chat ni SMS ouvert, au plus une page toutes les 2 secondes par site.

Repères : **[V]** vérifié (page lue le 24/11/2026, adresse donnée dans le tableau, les fiches ou les sources), **[I]** inféré (déduit d'éléments vérifiés), **[S]** supposé (non vérifié). Prix en dollars américains, tels qu'affichés le 24/11/2026. La colonne « Adresse » donne l'adresse du site ; l'adresse postale est dans les fiches.

Outils : recherche par Parallel Search (requêtes génériques, sans mention de JR Diamond) ; lecture des pages par **curl tel quel** (identité par défaut, sans changement) ; pour les pages chargées en JavaScript, un Chromium sans écran (Playwright, identité « HeadlessChrome » non modifiée). Les seuls contrôles « actionnés » sont des ouvertures d'adresses de filtre déjà présentes dans les menus (recherche de diamants synthétiques marquise chez Princess Jewelry). Les configurateurs 3D n'ont pas été manipulés.
